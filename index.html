전체 핸디 현황

등록된 모든 플레이어를 핸디 낮은 순으로 표시합니다. 핸디 = 최근 12경기에서 최고·최저 제외한 10경기 평균 (12경기 미만도 동일, 2경기 이하는 전체 평균).

이름핸디경기수직전 경기

오늘의 플레이어

함께 칠 사람을 선택하면 서로 주고받는 핸디(정수)를 계산합니다.

핸디 표

이름경기수평균타수받는 핸디

‘받는 핸디’ = 평균이 가장 낮은 사람을 0으로 두고, 평균 차이를 내림(버림)한 타수. 승패는 실제타수−핸디(=net)로 겨룹니다.

경기 기록

스코어 입력

정산할 경기

경기입력에서 저장한 경기의 핸디 적용 순위로 비용을 나눕니다.

① 비용 · 결제자 · 내기 포함

금액은 전체 합계로 입력. ‘각자 결제’는 각자 똑같이 나눠 이미 낸 것으로 봅니다. 내기 체크를 풀면 그 항목은 인원수로 똑같이 나눕니다.

② 내기 비율

순위별로 내기 포함 비용을 부담하는 비율(%)입니다.

③ 정산 결과

‘카톡 공유’는 휴대폰 공유창에서 카카오톡을 고르면 됩니다. 공유창이 안 뜨는 곳(PC·카톡 안 브라우저)에서는 복사되니 카톡에 붙여넣기 하세요.

누적 승패

핸디를 적용해 저장된 경기의 순위 누적입니다. (앱에서 저장한 경기만 집계)

이름경기🥇🥈🥉4위평균순위

평균순위 = 참가한 경기 순위의 평균 (낮을수록 좋음). 경기 수가 달라도 비교할 수 있습니다.

경기 이력 ▾ 펼치기

플레이어 등록

핸디 = 평균 타수(예: 92). 기록이 없는 새 플레이어는 입력한 핸디로 계산하고, 5경기가 쌓이면 실제 기록 평균으로 자동 전환됩니다.

☁ 클라우드 동기화 켜는 법 (한 번만)
  1. Firebase 콘솔에서 프로젝트 생성 (무료)
  2. 왼쪽 빌드 → Realtime Database → 데이터베이스 만들기 → 테스트 모드로 시작
  3. 프로젝트 설정(⚙) → 내 앱 → 웹앱(</>) 추가 → firebaseConfig 값 복사
  4. 이 index.html 파일을 열어 상단 FIREBASE_CONFIG에 붙여넣고 저장
  5. 파일을 Netlify·GitHub Pages 등에 올리면 링크로 여럿이 같은 기록을 공유합니다
